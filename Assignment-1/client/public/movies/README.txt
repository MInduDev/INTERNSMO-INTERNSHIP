WATCHSPACE MOVIE STORAGE FOLDER
===============================
Place your full movie files (e.g. .mp4, .webm) in this folder:
  d:\PROJECT\INTERNMO\NETFLIX\client\public\movies\

HOW TO USE IN WATCHSPACE:
When adding a movie in the Admin Panel (Titles Catalog -> Add Movie), in the "Video Stream URL" field enter:
  /movies/your-movie-filename.mp4

Example:
  If your file is named "interstellar.mp4" placed in this folder, use:
  /movies/interstellar.mp4

The video player will automatically load and stream the local full movie file!
